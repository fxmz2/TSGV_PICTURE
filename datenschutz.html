2. Grundsatz: Deine Daten bleiben auf deinem Gerät

Die App „Match-Shot“ läuft vollständig in deinem Browser. Alle Inhalte, die du eingibst oder hochlädst – insbesondere Spielernamen, Spielerfotos, Gegner, Sponsoren, Hintergründe, Termine und Einstellungen – werden ausschließlich lokal auf deinem Gerät im Speicher des Browsers (IndexedDB) abgelegt. Diese Daten werden nicht an uns oder an Dritte übertragen.

Auch die erstellten Grafiken werden direkt auf deinem Gerät berechnet. Sie werden nur dann weitergegeben, wenn du sie selbst über die Teilen-Funktion deines Geräts versendest oder speicherst.

Über die Funktion „Backup“ kannst du deine Daten als Datei auf deinem Gerät speichern. Diese Datei enthält auch die Spielerfotos. Bitte bewahre sie sorgfältig auf.

5. Vereinscode (Freischaltung)

Zur Freischaltung wird der eingegebene Vereinscode im Browser mit einer Liste auf unserem Server abgeglichen. Dabei wird lediglich diese Liste sowie ggf. das Vereinswappen vom Server geladen; der Code selbst wird nicht an uns übermittelt oder gespeichert. Der freigeschaltete Verein sowie das Ablaufdatum der Lizenz werden lokal auf deinem Gerät gespeichert. Beim Start der App wird die Liste erneut geladen, um Verlängerungen oder Sperrungen zu übernehmen. Der Demo-Modus funktioniert vollständig ohne diese Prüfung.

5a. Freistellen von Spielerfotos (KI auf dem Gerät)

Die Funktion „Hintergrund entfernen“ nutzt ein KI-Modell (MediaPipe, Google, Apache-Lizenz 2.0), das von unserem Server geladen wird und anschließend ausschließlich lokal auf deinem Gerät ausgeführt wird. Die Fotos verlassen dein Gerät dabei nicht. Die in der Bibliothek ursprünglich enthaltene Übermittlung von Nutzungsstatistiken an Google haben wir deaktiviert; zusätzlich verhindert eine Sicherheitsrichtlinie (Content Security Policy) jede Verbindung der App zu fremden Servern.
