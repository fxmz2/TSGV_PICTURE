# Freigeschaltete Vereine (Lizenz-/Vereinscodes)
#
# Format pro Zeile:
#   CODE-HASH = Vereinsname = Wappen-Datei = gültig bis
#
# - Den CODE-HASH (64 Zeichen) erzeugst du mit code-generator.html.
#   So steht der eigentliche Code nicht lesbar in dieser Datei.
# - Lesbare Codes (z.B. 548-962 = TSGV Rechberg = ...) funktionieren weiterhin,
#   sind aber für jeden sichtbar, der diese Datei im Browser aufruft.
#   Mit code-generator.html ("Bestehende Liste umwandeln") kannst du sie umwandeln –
#   die Codes der Vereine bleiben dabei gleich.
# - Die Wappen-Datei liegt auf dem Server (Pfad relativ zur index.html),
#   z.B. Wappen/TSGV_Rechberg.jpg. Groß-/Kleinschreibung beachten, keine Umlaute.
#   Ohne Wappen das Feld leer lassen:  HASH = Verein =  = 2050-12-31
# - "gültig bis" ist das Ende der Saisonlizenz (JJJJ-MM-TT oder TT.MM.JJJJ).
#   Zum Verlängern einfach das Datum ändern – die App übernimmt es beim
#   nächsten Start mit Internet. Ohne Datum ist der Code unbegrenzt gültig.
# - Wird eine Zeile gelöscht, ist der Code beim nächsten Start (mit Internet)
#   automatisch gesperrt.
# - Der Code DEMO ist fest in der App eingebaut (Demo-Modus mit Wasserzeichen)
#   und muss hier nicht eingetragen werden.
# - Zeilen mit # am Anfang sind Kommentare.
